# FADER_X X Air OSC mappings

This case covers [FADER_X issue #5](https://github.com/stagehacks/FADER_X/issues/5).
It compiles and runs the production address generator for X Air and X32 targets,
then checks that the firmware receive paths and configuration UI expose the same
supported targets.

The automated result proves address selection and range rejection. A FADER_X
owner with an XR12, XR16 or XR18 must confirm two-way movement on real hardware.
